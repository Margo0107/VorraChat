# VorraChat

Realtime chat application built with Next.js, Socket.io, Node.js and MongoDB.

# Features
- Registration
- Authentication
- Realtime messaging
- Responsive UI
- Socket.io integration
- JWT authorization
- MongoDB database

## Tech Stack
Frontend:
- React
- Next.js
- Tailwind CSS
- Socket.io-client

Backend:
- Node.js
- Express
- MongoDB
- Socket.io

## Installation
bash:
npm install
Frontend: npm run dev

Backend: npm run dev
